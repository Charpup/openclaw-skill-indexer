# Skill Indexer 📚

Scan and index all OpenClaw skills for easy discovery and management.

## When to Use

- Finding available skills in your OpenClaw installation
- Searching skills by trigger keywords or descriptions
- Automatically updating TOOLS.md with skill catalog
- Building cross-session skill registries

## Quick Start

```bash
cd ~/.openclaw/skills/skill-indexer
npm install
npm run index        # Build index
npm run update-tools # Update TOOLS.md
```

## CLI Usage

```bash
# Build or update the skill index
skill-indexer index

# Search skills by keyword
skill-indexer search "docs"
skill-indexer search "task"

# Show detailed skill information
skill-indexer info triadev

# List all indexed skills
skill-indexer list
skill-indexer list --type=system

# Update TOOLS.md auto-generated section
skill-indexer update-tools

# Validate index integrity
skill-indexer validate
```

## Programming API

```javascript
const { SkillIndexer } = require('skill-indexer');

const indexer = new SkillIndexer();

// Build index
await indexer.buildIndex();

// Search skills
const results = indexer.search('docs');

// Find by trigger
const byTrigger = indexer.findByTrigger('search docs');

// Get skill details
const skill = indexer.getSkill('triadev');

// Update TOOLS.md
await indexer.updateToolsMd();
```

## How It Works

1. **Scan** - Discovers SKILL.md files in `~/.openclaw/skills/` and `workspace/skills/`
2. **Parse** - Extracts metadata from YAML frontmatter (name, description, version, triggers)
3. **Index** - Builds searchable index with lookup maps
4. **Store** - Saves to `~/.openclaw/.skill-index.json` with backup rotation
5. **Export** - Updates TOOLS.md with auto-generated skill catalog

## Index Format

```json
{
  "version": "1.0.0",
  "generatedAt": "2026-02-26T11:36:56Z",
  "stats": { "total": 13, "system": 13, "workspace": 0 },
  "skills": [...],
  "byTrigger": { "search docs": ["docs-rag"] },
  "byKeyword": { "rag": ["docs-rag"] }
}
```

## TOOLS.md Integration

Automatically maintains this section in TOOLS.md:

```markdown
<!-- SKILL-INDEX-START -->
<!-- Auto-generated by skill-indexer. Do not edit manually. -->

| Skill | Description | Triggers |
|-------|-------------|----------|
| docs-rag | Query OpenClaw docs... | openclaw docs, search docs |
| ... | ... | ... |

<!-- SKILL-INDEX-END -->
```
